# KAKALA EMMANUEL

> Personal portfolio website — bold, modern, AI-inspired.

**Live demo:** Enable GitHub Pages (Settings → Pages → Deploy from `main` branch / root)

## Pages
1. **Home** – Hero with animated title
2. **About** – Story & journey
3. **Projects** – Showcase
4. **Skills** – Tech stack & abilities
5. **Contact** – Get in touch

## Features
- Neon / AI aesthetic (cyan + purple glow)
- Glassmorphism UI
- Smooth scroll animations
- Fully responsive
- Pure HTML / CSS / JS (no build step)

## How to run locally
Just open `index.html` in a browser, or use any static server.
